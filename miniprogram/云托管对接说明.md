# 小程序对接云托管说明

## 配置

编辑 `miniprogram/utils/config.js`：

| 字段 | 说明 |
|------|------|
| `envId` | 云环境 ID，当前 `prod-d3g1vkrj3290d085e` |
| `serviceName` | 云托管「服务名称」，须与控制台一致（当前为 `alllink-server`） |
| `useCallContainer` | `true` 走 `wx.cloud.callContainer` |
| `baseUrl` | 可选；本地调试或上传兜底时填公网域名，如 `https://alllink-server-305818-11-1467541248.sh.run.tcloudbase.com` |

## 数据来源

小程序首页/Banner/门店/菜单/异业/供应链/积分/订单/入驻/推荐/商户工作台等，均读取后端 `/api/*`。后台运营台维护的图片（封面、商品图、Banner、证照）会随接口下发。

## 部署后

1. 云托管发布最新后端 `main`
2. 开发者工具打开小程序，确认「云开发 / 云托管」环境一致
3. 用演示码登录：`C001` / `D001` / `Y001` / `G001`
