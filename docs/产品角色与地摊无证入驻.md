# 产品角色对齐（说明书 V11.16 → 微信小程序生产）

对照客户《万业互联云--使用说明书》与当前微信小程序落地版。

## 1. 登录身份（四类，对齐说明书）

| 说明书 | 生产 JWT / 会话 | 入口 |
| --- | --- | --- |
| 消费者 consumer | `consumer` | C 端 Tab |
| 商家 merchant | 内部 `stall` / `cross` / `supply`（展示为商家） | `/merchant/home/home` |
| 合伙人 partner | `partner` | `/partner/home/home` |
| 创始人 founder | `founder` | `/founder/home/home` |
| 负责人 lead | `founder` 会话 + `isLead`（权限子集） | `/pages/identity-apply/identity-apply?role=lead` |

供应链**不再**作为独立登录主身份；入驻时作为「商家经营类型：供应链供货」。

身份切换：`/pages/identity/identity`（任意已登录角色可进）。

## 2. 商家经营类型（shopType）

| 类型 | 证照 | 说明 |
| --- | --- | --- |
| 地摊 stall | 身份证 + 摊位照 + 合规承诺；食品证选填 | 无营业执照可申 |
| 异业 cross | 营业执照 + 法人证 + 门店照 + 信用代码 | — |
| 供应链供货 supply | 同异业（仓库/门店照） | 供货能力，非独立端 |

## 3. 合伙人闭环

1. C 端/身份页 → 申请合伙人 → `partner_applications`
2. 创始人审核通过 → `users.is_partner=1`
3. 切换到合伙人 → 佣金概览 / 提现申请 → 创始人审核

## 4. 创始人 / 负责人闭环

1. 身份页申请 → 填姓名+手机号 → `platform_role_applications`
2. Web 超管/创始人在「身份授权」审核通过 → `is_founder` / `is_lead`
3. 小程序轻控制台：总览 + 商家入驻 / 合伙人 / 提现审核

## 5. Web 后台账号（默认密码均为 `123456`）

| 账号 | 角色 | 说明 |
| --- | --- | --- |
| `admin` | 超级管理员 | 全部页面；数据大屏入口已默认隐藏 |
| `founder` | 创始人 | 审核、名单授权、订单积分等 |
| `partner` | 合伙人 | 合伙人运营 / 采购 / 推荐 |
| `lead` | 负责人 | 创始人权限子集 |

启动时 `ensureRbacBootstrap` 自动建角色与账号。
