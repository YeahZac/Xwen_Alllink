## 云托管环境变量（必配，勿提交 Git）

在微信云托管服务「环境变量」中配置（与本地 `backend/.env` 对齐）：

- `WX_APPID` / `WX_APP_SECRET`
- `WX_PAY_MCH_ID` = `1117474896`
- `WX_PAY_API_V3_KEY`
- `WX_PAY_SERIAL_NO`
- `WX_PAY_PUBLIC_KEY_ID`
- `WX_PAY_NOTIFY_URL` = `https://wanye.cloud/api/wxpay/notify`
- `PUBLIC_BASE_URL` = `https://wanye.cloud`
- `WX_PAY_MODE=auto`、`WX_PAY_ALLOW_DIRECT=1`、`WX_PAY_PROFIT_SHARING=1`

私钥二选一：

1. 把 `apiclient_key.pem` / `pub_key.pem` 挂到容器 `secrets/wxpay/`，并设  
   `WX_PAY_PRIVATE_KEY_PATH` / `WX_PAY_PUBLIC_KEY_PATH`
2. 或把 PEM 全文写入 `WX_PAY_PRIVATE_KEY` / `WX_PAY_PUBLIC_KEY`（含 `-----BEGIN…-----`）

配置后**重新发布**服务。可用运营台登录后请求：

```http
GET /api/wxpay/config-check
```

检查 `configured`、`notifyUrl` 是否正确。

## 首个上线场景验收

1. C 端微信登录（openid 必须有，否则无法 JSAPI）
2. 扫地摊收款码 → 输入金额 → 拉起微信支付
3. 支付成功 → 回调或 `/api/orders/pay/sync` 入账 → 积分到账
4. 点餐下单现金部分同样拉起支付

分账（平台抽成 + 推广员）在二级商户进件并开启收付通分账接收方后再联调；订单侧已预留 `profit_sharing` 标记。
