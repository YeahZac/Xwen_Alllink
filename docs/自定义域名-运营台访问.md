# 自定义域名访问运营台（admin.wanye.cloud）

## 访问地址

| 用途 | URL |
|------|-----|
| 运营后台（推荐） | **https://admin.wanye.cloud/** |
| 健康检查 | https://admin.wanye.cloud/api/health |
| 兼容旧路径 | https://admin.wanye.cloud/admin/ → 会跳到 `/` |

登录账号：`admin` / `123456`（超级管理员）

在 `admin.wanye.cloud` 下，打开根路径即可进入后台，无需再加 `/admin/`。

## 云托管控制台

1. **服务 → 自定义域名**  
   - 绑定 **`admin.wanye.cloud`** 到本 API 服务  
   - 证书状态正常
2. **DNS**  
   - `admin.wanye.cloud` CNAME 指向云托管给出的目标
3. **环境变量**（保存后**重新发布**）  
   ```text
   PUBLIC_BASE_URL=https://admin.wanye.cloud
   ADMIN_HOST=admin.wanye.cloud
   ```
4. **发布**最新代码版本

## 验证

1. https://admin.wanye.cloud/api/health → `data.db.ok === true`，`data.adminUrl` 为 `https://admin.wanye.cloud/`
2. https://admin.wanye.cloud/ → 出现运营台登录页
3. `admin` / `123456` 登录成功

## 说明

- 后台页面与 `/api` 同域，前端请求 `/api/...`，无需额外 CORS。
- 若另有 `api.wanye.cloud` 仅作接口域名，也可绑定到同一服务；浏览器打开运营台请用 **admin** 子域。
