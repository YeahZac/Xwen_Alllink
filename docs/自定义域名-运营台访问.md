# 自定义域名访问运营台（api.wanye.cloud）

## 访问地址

| 用途 | URL |
|------|-----|
| 运营后台 | https://api.wanye.cloud/admin/ |
| 健康检查 | https://api.wanye.cloud/api/health |
| 根路径（浏览器） | https://api.wanye.cloud/ → 自动跳转 `/admin/` |

登录账号：`admin` / `123456`（超级管理员）

## 云托管控制台检查清单

1. **服务 → 自定义域名**  
   - 已添加 `api.wanye.cloud`（或父域 `wanye.cloud` 下的该子域）  
   - 域名状态为「已生效 / 已配置证书」
2. **DNS**  
   - `api.wanye.cloud` CNAME 指向云托管给出的解析目标（你已解析到 api.wanye.cloud 对应记录即可）
3. **环境变量**（服务设置 → 环境变量 → 保存后**重新发布**）  
   ```text
   PUBLIC_BASE_URL=https://api.wanye.cloud
   ```
4. **发布**  
   - 拉取含本说明的最新代码并发布版本，使根路径跳转与 `PUBLIC_BASE_URL` 生效

## 验证步骤

1. 打开 https://api.wanye.cloud/api/health  
   - `data.db.ok` 应为 `true`  
   - `data.adminUrl` 应为 `https://api.wanye.cloud/admin/`
2. 打开 https://api.wanye.cloud/admin/  
   - 出现运营台登录页
3. 用 `admin` / `123456` 登录，侧栏应能看到门店/审核等菜单

## 说明

- 运营台与 API 同域同源，前端请求 `/api/...`，**不必再配跨域**。
- 小程序合法域名若要用该域名请求业务接口，需在微信公众平台把 `https://api.wanye.cloud` 配进 request 合法域名（与运营台访问无关）。
