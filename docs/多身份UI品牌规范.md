# 万业互联云 · 多身份 UI / 品牌规范

对齐 C 端「我的」列表与首页店卡，商家 / 合伙人 / 创始人 / 负责人共用同一套视觉尺度。实现载体：`miniprogram/styles/role-kit.wxss` + `tokens.wxss`。

## 品牌

| Token | 值 | 用途 |
| --- | --- | --- |
| 主色 | `#FF4D4F` | CTA、金额、选中态 |
| 强调橙 | `#FF7A45` | 渐变起点 |
| 页面底 | `#F7F4F0` | 暖米底 |
| 卡片面 | `#FFFFFF` | 列表卡 / 宫格 / 英雄卡 |
| 辅文 | `#8F959E` | 说明、副标题 |
| 正文墨 | `#1F2329` | 主标题 |
| 圆角大卡 | `36rpx` | 列表卡、页头、KPI |
| 圆角宫格 | `28rpx` | 双列入口 |
| 阴影 | `0 6rpx 20rpx rgba(31,35,41,.05)` | 白卡抬起 |

## 字号（rpx，微信可读下限）

| 层级 | 字号 | 行高 | 场景 |
| --- | --- | --- | --- |
| 导航标题 | 34 | 1.3 | `m-page-head__title` / page-nav |
| 英雄店名 | 40 | 1.25 | 身份首页 `shop-card__name` |
| 卡片主标题 | 30 | 1.35 | `role-card__title` / `menu-tile__title` |
| 正文 / 按钮 | 28 | 1.4 | 表单、主按钮、空态 |
| 辅助说明 | 24 | 1.45 | `role-card__sub`、状态条 |
| 底栏文案 | 22 | 1.25 | `role-tabbar`（不低于 22） |
| KPI 数字 | 36–40 | 1.25 | 首页三列指标 |

**硬规则：** 身份列表主副文案最多 **2 行省略**，禁止 `ellipsis-1` / `white-space: nowrap` 把关键信息裁成一行残缺。

## 控件尺度

| 控件 | 规格 |
| --- | --- |
| 主按钮 | 高 88rpx · 字 28rpx · 圆角随品牌 |
| 列表内小按钮 | 高 64rpx · 字 24rpx · 最小宽 128rpx |
| 搜索框 / 输入 | 高 88rpx · 字 28rpx · 内边距 24rpx |
| 筛选 Chip | 字 24rpx · 上下 14rpx · 左右 24rpx |
| 底栏 | 高 112rpx + safe-area · 图标 48×48 · 文案 22 |
| 印戳 / seal | 72×72 · 圆角 20rpx |
| 列表缩略图 | 120×120 · 圆角 20rpx |

## 列表与布局

| 元素 | 规格 |
| --- | --- |
| 页左右边距 | 24rpx |
| 列表卡最小高 | **184rpx** |
| 卡内 padding | 28–32rpx |
| 卡间距 | 16rpx |
| 卡宽 | 屏宽 − 48rpx（满宽白卡，勿再缩窄） |
| 功能宫格 | 双列 · 宽 `calc(50% - 8rpx)` · 最小高 **200rpx** |
| 带底栏页底距 | `112rpx + 28rpx + safe-area` |

类名约定：

- 列表容器：`role-list`
- 列表行：`role-card`（带操作：`role-card--stack` + `role-card__actions`）
- 宫格：`menu-grid` / `menu-tile`
- 底栏页根节点：`page page--tabbed`（首页壳加 `page--flush m-home`）

## 场景对照

| 场景 | 结构 |
| --- | --- |
| 商家 / 合伙人 / 创始人首页 | 英雄卡 + KPI + 双列宫格 + 操作栈 + 底栏 |
| 订单 / 账目 / 成员 / 日志 | `m-page-head` + `role-list` + `role-card` |
| 身份切换页 | `id-card` 最小高 176rpx，描述 2 行 |
| C 端「我的」 | 仍可用 `m-row`；身份工作台优先 `role-card` |

新增身份页时：**先套 role-kit 类名，禁止另起一套矮行 / 小字号。**
