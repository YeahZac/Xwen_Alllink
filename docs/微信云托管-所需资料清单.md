# 微信云托管 · 部署所需资料清单

> 数据库脚本与后端代码已就绪。**云托管账号侧配置需你提供以下信息后**，我才能继续协助：连库、执行脚本、发布服务、绑定小程序合法域名。

## 一、账号与权限（必填）

请确认并告知：

| 项 | 说明 | 你需要提供的内容 |
|----|------|------------------|
| 微信小程序 AppID | 正式/测试号 | AppID 字符串 |
| 小程序管理员/开发者 | 能登录[微信公众平台](https://mp.weixin.qq.com) | 是否已开通「云托管」 |
| 云托管环境 | 控制台 → 云托管 → 环境 | **环境 ID**（如 `prod-xxxxx`） |
| 操作权限 | 需能创建服务、开通 MySQL、配置环境变量 | 你是否有管理员权限 |

## 二、MySQL（必填）

在云托管控制台开通 MySQL 后，请提供：

| 项 | 示例 | 用途 |
|----|------|------|
| 内网地址 HOST | `10.x.x.x` 或控制台给出的 host | `DB_HOST` |
| 端口 | `3306` | `DB_PORT` |
| 数据库名 | 建议 `wanyehulian`（脚本已用此名） | `DB_NAME` |
| 用户名 | `root` 或控制台账号 | `DB_USER` |
| 密码 | **** | `DB_PASSWORD` |
| 是否允许外网临时访问 | 是/否 | 用于首次远程执行 SQL；若否，需你在控制台「SQL 窗口」自行执行 `01_schema.sql` + `02_seed.sql` |

## 三、服务发布（必填）

| 项 | 说明 |
|----|------|
| 服务名称 | 建议 `xwen-alllink-api` |
| 部署方式 | Dockerfile（本仓库已含） |
| Git 仓库 | `https://github.com/YeahZac/Xwen_Alllink.git` |
| 分支 | 建议 `main` |
| 构建目录 | 若仓库根即 backend，填 `.`；若 monorepo 含 frontend，填 `backend` |
| 容器端口 | `80`（已与 Dockerfile / container.config.json 一致） |

## 四、环境变量（服务发布时配置）

```text
NODE_ENV=production
PORT=80
DB_HOST=（云托管 MySQL 内网地址）
DB_PORT=3306
DB_USER=...
DB_PASSWORD=...
DB_NAME=wanyehulian
JWT_SECRET=（随机长字符串，务必保密）
WX_APPID=（小程序 AppID）
WX_APP_SECRET=（小程序 AppSecret，仅服务端）
```
