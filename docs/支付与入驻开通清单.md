# 万业互联云 · 支付开通 & 异业/供应链入驻清单

用途：按顺序勾选。当前产品侧「点餐码路径、入驻申请、模拟支付」已通；**真实收款进店主钱包 + 平台抽成**必须做完 A→D。  
勾选方式：把 `- [ ]` 改成 `- [x]`。

---

## 总览：要开哪些平台

| 平台 | 干什么 | 是否必须 |
|------|--------|----------|
| [微信公众平台](https://mp.weixin.qq.com)（小程序） | AppID、域名、类目、用户隐私、发布 | 必须 |
| [微信云托管](https://cloud.weixin.qq.com) | 后端、MySQL、环境变量、发版 | 必须 |
| [微信支付商户平台 / 服务商](https://pay.weixin.qq.com) | 普通商户号不够，要走**服务商 + 平台收付通** | 真实支付必须 |
| [微信支付合作伙伴平台](https://partner.weixin.qq.com)（若你们走服务商入驻） | 服务商资质、产品开通、二级商户进件 | 真实支付必须 |
| 运营后台（云托管域名 `/admin/`） | 审入驻、开城、看抽成/账单 | 业务运营必须 |
| ICP/平台资质（收付通审核常要） | 平台资质证明 | 收付通审核常要 |

> 说明：你之前进过的「商户平台」≠「服务商后台」。**平台收付通**在服务商/合作伙伴侧开通，不是普通商户「产品中心」里随便点一项。

## C. 微信支付 · 服务商与平台收付通（支付主路径）

### C1. 资质与入驻

- [ ] 主体已具备申请**微信支付服务商**的资质（或已绑定现有服务商）
- [ ] 在正确后台完成服务商入驻（合作伙伴平台 / 服务商通道，**不要**只用普通商户号当平台）
- [ ] 服务商审核状态：已通过（记录商户号/服务商号）
- [ ] 已申请开通 **平台收付通**（或当前政策下的等价「电商收付通/平台模式」产品）
- [ ] 平台收付通审核所需材料已齐（常见：平台资质、ICP/EDI 相关证明——**域名备案 ≠ ICP 许可证**，按微信审核页要求准备）
- [ ] 产品状态显示「已开通 / 可进件」

### C2. 技术参数（配到云托管环境变量）

- [ ] `WX_PAY_MCH_ID`（服务商商户号）
- [ ] `WX_PAY_API_V3_KEY`（APIv3 密钥）
- [ ] `WX_PAY_SERIAL_NO`（证书序列号）
- [ ] 商户 API 证书私钥 / 证书文件已安全放入云托管（**勿提交 Git**）
- [ ] 支付结果通知 URL 已规划（云托管 HTTPS 回调，后续开发对接）
- [ ] 配置后**重新发布**云托管服务

### C3. 二级商户（每个门店一个）

- [ ] 明确进件流程：异业门店 / 供应链 /（可选）地摊 如何在服务商侧进件拿**二级商户号**
- [ ] 进件材料清单已发给合作商户（营业执照、法人身份证、结算账户等——地摊若无执照按微信允许的主体类型准备）
- [ ] 二级商户号回写到系统字段 `merchants.wx_sub_mch_id`（运营后台或接口）
- [ ] 至少 1 家异业 + 1 家供应链 完成进件绑定，可做真实收款联调

### C4. 分账 / 抽成

- [ ] 平台作为分账接收方已在微信侧配置
- [ ] 抽成比例与后台 `commission_*` / 等级规则一致
- [ ] 明确：先入账二级商户 → 再分账到平台（或收付通规定的结算路径）
- [ ] （开发项）JSAPI 预下单返回真实 `payParams`，小程序 `wx.requestPayment` 可拉起
- [ ] （开发项）支付回调验签、入账、分账、退款、对账

> 未完成 C 之前：小程序仍可能是 `wxpay_sim` 模拟入账，**钱不会进店主微信钱包**。

## D. 业务侧：邀请异业门店入驻

### D1. 开城与规则

- [ ] 运营后台已开通目标城市（如深圳各区）
- [ ] 异业入驻材料规则已确认：营业执照、身份证、门店照片、地图定位、统一社会信用代码
- [ ] 推荐奖励规则已在后台配置（如需要）

### D2. 邀约物料

- [ ] 准备邀约话术（积分客流、兑换规则、抽成与体验期说明）
- [ ] 生成/打印「申请入驻」小程序路径或太阳码（进 `/pages/apply/apply?role=cross`）
- [ ] 准备推荐人邀请码（运营或地推人员的 C 端/商户邀请码）
- [ ] 明确：入驻手机号尽量与微信绑定手机一致，便于身份切换

### D3. 首批异业验收（建议 ≥3 家）

- [ ] 商户提交申请 → 运营后台审核通过
- [ ] 商户能切到「异业」工作台，上架兑换商品（积分价/现金价）
- [ ] C 端「兑换」页能搜到该店，能下单核销
- [ ] （支付开通后）该店 `wx_sub_mch_id` 已绑定，现金支付进店主账户

## E. 业务侧：邀请供应链入驻

### E1. 规则

- [ ] 供应链入驻材料已确认：营业执照、身份证、信用代码、地图定位（仓库照可选）

- [ ] 推荐码与地推流程与异业一致

### E3. 首批供应链验收（建议 ≥2 家）

- [ ] 审核通过，能进供应链工作台
- [ ] 可上架供货商品、看采购需求、接采购单
- [ ] 地摊/异业可向其采购；采购完成后额度池入账符合规则
- [ ] （支付开通后）货款结算路径与二级商户绑定完成

## G. 你现在就可以先做、不必等开发的事项

优先做这些（不堵代码）：

1. **确认服务商 + 平台收付通审核进度**（卡在哪一步、缺什么材料）  
2. **锁定首批异业 3 家、供应链 2 家**，发材料清单与申请入口  
3. **开城、运营账号、推荐码**准备好  
4. **收齐服务商号 / APIv3 / 证书**，放到云托管环境变量（可先配，开发再接预下单）  
5. 把本清单勾选情况发我：我可以按「已勾 / 未勾」标出下一步是商务审核还是开发联调
